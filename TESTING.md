# Тестирование ML-сервиса

Для проверки работоспособности системы написаны интеграционные тесты, которые запускаются против реально поднятого окружения через Docker Compose.

## Требования

- Запущенный Docker
- Python 3.12+
- Виртуальное окружение (рекомендуется)

## Как запустить тесты

1. **Поднять приложение** из корня проекта:

   ```bash
   docker compose up --build
   ```

2. **Создать и активировать виртуальное окружение** (Windows):

   ```powershell
   python -m venv venv
   venv\Scripts\activate
   ```

   (Linux/macOS):

   ```bash
   python -m venv venv
   source venv/bin/activate
   ```

3. **Установить зависимости для тестов**:

   ```bash
   pip install -r requirements-dev.txt
   ```

4. **Запустить тесты**:

   ```bash
   pytest tests/
   ```

## Покрытые сценарии

### 1. Auth
- Регистрация нового пользователя
- Повторная регистрация с тем же именем → ошибка 400
- Успешная авторизация
- Неверный пароль → 401
- Несуществующий пользователь → 401

### 2. Balance
- Получение начального баланса (0.00)
- Пополнение баланса
- Пополнение на отрицательную сумму → 422
- Пополнение на ноль → 422
- Доступ без токена → 401

### 3. Predict
- Успешная отправка текста на предсказание
- Списание 1 кредита после успешного предсказания
- Проверка, что задача завершилась (completed)
- Отправка при недостаточном балансе → 402
- Пустой текст → 422
- Запрос без токена → 401

### 4. History
- Сохранение и получение истории транзакций (пополнение и списание)
- Сохранение и получение истории предсказаний
- Доступ без токена → 401

## Структура тестов

```
tests/
├── conftest.py       # фикстуры и общие настройки
├── helpers.py        # вспомогательные функции для запросов
├── test_auth.py      # тесты /auth
├── test_balance.py   # тесты /balance
├── test_predict.py   # тесты /predict
└── test_history.py   # тесты /history
```
